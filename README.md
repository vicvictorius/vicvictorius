<h2 align="left">🚀 Featured Project</h2>

### Financial Management API

Backend REST API designed for financial management, built with a
production-oriented architecture.

**Key features:**

- RESTful API with FastAPI
- JWT authentication and authorization
- Financial transactions and categories
- Financial dashboard and monthly summaries
- PostgreSQL persistence
- SQLAlchemy ORM
- Database migrations with Alembic
- Automated tests with Pytest
- Dockerized application
- CI/CD with GitHub Actions
- Automated deployment

**Core stack:**

`Python` · `FastAPI` · `PostgreSQL` · `SQLAlchemy` · `Alembic` · `Pytest` · `Docker` · `GitHub Actions`
